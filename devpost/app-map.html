Reference route through the code

Stop 1

looks_like_hackathon_page

Checks whether the paste has enough hackathon context to send for decoding. Bad input gets the friendly message before any API request.

Stop 2

extract_hackathon_details

Sends the page and About me to Gemini. The returned deadline stays raw; checklist items are reconciled with source bullets. Items not found in the source remain visible as not verified.

Stop 3

decode_deadline and render section

Python maps only supported timezone labels, converts safe dates to IST, and renders the three results. An unclear deadline does not hide eligibility or submission items.

This is a reference route through the committed source, not a record that the route was navigated live. Source commit: c93f0a1.

To change this, start here

Change what counts as a hackathon page

Start at looks_like_hackathon_page and keep its rejection message aligned with the paste rules in the PRD.

Change timezone labels or date formats

Start at FIXED_TIMEZONE_OFFSETS, TIMEZONE_SUFFIX_PATTERN, and DATE_TIME_FORMATS. Unsupported or ambiguous labels should keep the quoted fallback.

Change submission grouping or verification labels

Start at extract_submission_bullets and reconcile_submission_items. Source bullets are preserved; Optional cues include “To be considered for” and “optional”.

Change the model or install requirements

Start at .env.example for the model setting and requirements.txt for packages. Keep real credentials in the ignored local .env.

A practice to reuse

The saved AWS page exposed a mismatch between a model-generated checklist and the source bullets. The code now logs counts before and after reconciliation, preserves unmatched items as not verified, and offers retry when a submission section yields no items. On another project, compare extracted or generated results against the source and make missing or uncertain data visible instead of silently dropping it.

Run it again

  1. Set your own GEMINI_API_KEY in the local .env.
  2. Install dependencies with python -m pip install -r requirements.txt.
  3. Run streamlit run app.py and open the local URL printed in the terminal.
